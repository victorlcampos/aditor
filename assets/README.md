Style/medium: crisp minimalist flat graphic design, vector-like edges, premium developer-tool identity.
Composition/framing: wide 3:1 horizontal banner, centered complete lockup with generous negative space, dark charcoal background, bright warm orange symbol and off-white wordmark.
Text (verbatim): "Aditor"
Constraints: only this word, highly legible clean modern typography, no gradients, no mockup, no extra captions, no watermark.
