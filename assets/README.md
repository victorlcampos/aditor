# Visual identity

`aditor-logo.png` was created with the built-in image generation tool.

## Generation prompt

```text
Use case: logo-brand
Asset type: GitHub README brand banner for Aditor, a Rust command-line tool for AI agents to capture browser tabs and screens and edit video.
Primary request: Create a polished original logo lockup with a strong geometric A monogram that incorporates a video play triangle and a subtle editing cut, followed by the word Aditor.
Style/medium: crisp minimalist flat graphic design, vector-like edges, premium developer-tool identity.
Composition/framing: wide 3:1 horizontal banner, centered complete lockup with generous negative space, dark charcoal background, bright warm orange symbol and off-white wordmark.
Text (verbatim): "Aditor"
Constraints: only this word, highly legible clean modern typography, no gradients, no mockup, no extra captions, no watermark.
```

## Contrast correction

The logo was edited with the built-in image generation tool to use a dark wordmark on an opaque white background, keeping it readable in both light and dark GitHub themes.

```text
Use case: logo-brand
Edit target: the attached original Aditor logo. Preserve the orange A/play monogram shape, proportions, editing cut, and the Aditor wordmark spelling and typography. Fix readability on white GitHub pages: change the wordmark to very dark charcoal (#171717) and use a fully opaque solid white background across the entire canvas. The background must be baked into the PNG: no transparency or alpha cutout anywhere. Clean crisp flat edges, no speckling, no distressed texture. Keep the centered wide horizontal lockup with generous margins. Text (verbatim): Aditor. No extra text.
```
