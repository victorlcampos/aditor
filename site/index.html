GOOD TO KNOW

Small tool.
Clear boundaries.

Does it work with my agent?+

If your agent can run terminal commands, it can use Aditor. Commands use explicit IDs and flags, support JSON output, and return nonzero exit codes on failure. Aditor does not require a specific agent framework.

What can browser capture see?+

Capture the visible tab area, without browser chrome or audio, or target a unique CSS element. Element capture does not cross iframe or shadow DOM boundaries. Recording a selected element requires its dimensions to stay fixed. Read the browser setup guide.

Can I record my whole screen?+

Yes. Native capture uses AVFoundation on macOS, X11 on Linux, and GDI on Windows. Monitor selection through --screen is available on macOS, where the terminal needs Screen Recording permission. Use --video-device on Linux and Windows.

Where does Aditor install itself?+

Run --install to copy the CLI to ~/.local/bin on macOS/Linux or %LOCALAPPDATA%\Aditor\bin on Windows. It configures your shell profile or Windows user PATH. Open a new terminal afterward. Use --install-dir for a custom folder or --no-modify-path to manage PATH yourself.

Is Aditor open source?+

Yes. Aditor is written in Rust and distributed under the MIT license. FFmpeg and ffprobe have their own licenses. Explore the code, suggest a feature, or contribute on GitHub.
